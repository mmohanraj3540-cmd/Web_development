# Accessible HTML5 Portfolio

A multi-page personal portfolio created for the assignment:

**HTML5 Semantic Structure & Accessibility**

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Accessible contact form

## Requirements covered
- Semantic HTML5 elements: `header`, `nav`, `main`, `section`, `article`, `footer`
- Skip-to-content link
- Keyboard/tab navigation
- Visible keyboard focus states
- Accessible form labels and required-field semantics
- ARIA navigation/status attributes where useful
- Descriptive page titles and SEO meta descriptions
- Responsive layout
- Reduced-motion preference
- No external libraries or tracking scripts

## Testing
Open `index.html` in a browser, then run Chrome Lighthouse with:
- Mobile or Desktop
- Accessibility
- SEO

A 100 score cannot be guaranteed because Lighthouse results can vary by browser/version and environment. Verify the final deployed version before submission.
